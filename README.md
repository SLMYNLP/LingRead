# LingRead Dataset

**LingRead** is a large-scale benchmark dataset of reading passages designed for research on personalized passage recommendation, linguistic quality assessment, and educational content generation.

It is part of a broader project focused on fine-tuning large language models (LLMs) for personalized passage generation tailored to individual learners.

The dataset contains approximately **450,000 passages** annotated with expert linguistic quality scores. These annotations support the development of models that generate and recommend high-quality, learner-adapted reading materials.

## Dataset Overview

| Statistic                    | Value          |
|-----------------------------|----------------|
| Number of passages          | ~450,000       |
| Annotation type             | Expert linguistic quality scores |
| Domain                      | Language learning / educational reading materials |
| Language                    | English        |
| Primary use cases           | Personalized passage recommendation, linguistic quality assessment, LLM fine-tuning for educational content generation |

Each passage is associated with expert-annotated linguistic quality scores that capture syntactic, semantic, and discourse-level properties. These scores help guide the generation and selection of passages that are well-formed, coherent, and suitable for learners at different proficiency levels.

## Project Context

LingRead is developed as part of an initiative to fine-tune large language models for personalized passage generation. The goal is to enable LLMs to produce high-quality reading materials adapted to individual learner profiles, learning goals, and linguistic needs.
