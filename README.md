# LingRead Dataset

**LingRead** is a large-scale benchmark dataset of reading passages designed for research on personalized passage recommendation, linguistic quality assessment, and weakly supervised learning in language learning environments.

The dataset contains approximately **450,000 passages** annotated with expert linguistic quality scores. It is particularly suited for studying noise-aware recommendation, linguistic prior modeling, and robustness under weak supervision.

## Dataset Overview

| Statistic                    | Value          |
|-----------------------------|----------------|
| Number of passages          | ~450,000       |
| Annotation type             | Expert linguistic quality scores |
| Domain                      | Language learning / educational reading materials |
| Language                    | English        |
| Primary use cases           | Passage recommendation, linguistic noise modeling, quality assessment |

Each passage is associated with expert-annotated linguistic quality scores that capture syntactic, semantic, and discourse-level properties. These scores make LingRead especially useful for evaluating methods that incorporate linguistic priors (e.g., part-of-speech consistency, semantic role relationships, and contextual coherence).
